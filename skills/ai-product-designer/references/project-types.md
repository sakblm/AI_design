# Project type routing

## Availability

- **Ready**: Dedicated workflow and deliverable path are implemented and tested.
- **Beta**: The request can be executed, but dedicated templates or deterministic automation remain incomplete.
- **Planned**: Do not create a request from the Design Console. Explain that the dedicated implementation is not ready.

## Wireframe

Availability: Ready.

Use the bundled wireframe kit. Optimize for structure, flow, state, comparison, and annotation. Deliver local HTML; keep it static unless interaction is explicitly requested.

- `structural-wireframe`: neutral structural review artifact
- `detailed-wireframe`: content- and state-complete review artifact with neutral visual treatment

## UI Mockup

Availability: Beta.

Use the selected design system at high fidelity. Preserve rationale and state coverage. Deliver local HTML and representative renders. Do not imply production readiness.

## Slides

Availability: Planned until a dedicated slide template and validation path are added.

Create an HTML slide proposal or storyboard that uses the selected design system. Define audience, narrative, slide count, and presentation context. If the requester needs PPTX or Google Slides, also follow the presentation-specific workflow available in the environment.

## UX Audit

Availability: Ready.

Do not create screens by default. Deliver prioritized findings, evidence labels, consequence, severity, confidence, recommendation, and verification needed.

## User Flow

Availability: Planned until a dedicated diagram template and validation path are added.

Show entry points, primary path, branches, system states, failure and recovery, exits, and ownership boundaries. Use the smallest diagram format that remains reviewable.

## Design System Audit

Availability: Beta.

Compare supplied UI with registered tokens, components, content rules, and accessibility guidance. Separate direct violations from unknown or undocumented cases.

## Component Specification

Availability: Beta.

Define anatomy, variants, states, content rules, behavior, responsiveness, accessibility, analytics hooks, and implementation notes.

## Implementation Handoff

Availability: Beta.

Package the selected direction with specifications, assets, traceability, unresolved decisions, QA expectations, and implementation constraints. Do not change production code unless explicitly requested.
