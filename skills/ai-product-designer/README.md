# AI Product Designer

Codexで、既存UIやデザインシステムをもとに、画面改善案・ワイヤーフレーム・UIモックアップを作るSkillです。チャットで要件を聞き、ローカルHTML、レンダー画像、設計理由、QA記録を案件フォルダにまとめます。

## できること

- 現行UI・参考画像・デザインシステムを読み、改善案を整理する
- 構造ワイヤー／詳細ワイヤー／UIモックアップを選んで作る
- 画像が重要な画面では、実写真を使わずに画像枠・比率・画像なし状態まで検討する
- 構造ワイヤーと詳細ワイヤーは、共有しやすい単一HTMLでも出力する
- 画面数、状態、画像構造、表示崩れを品質チェックする

## インストール

1. `ai-product-designer.zip` を展開します。
2. 展開後の`ai-product-designer`フォルダを以下へ置きます。

   ```text
   ~/.codex/skills/ai-product-designer/
   ```

3. Codexを再起動するか、新しいタスクを開きます。


## 使い方

チャットで次のように呼び出します（$は/でも可）。

```text
$ai-product-designer 
```

Codexがまず作業フォルダ、作りたいもの、参照する現行UIやデザインシステムを確認します。画面を作る場合は、次の3つから仕上がりを選びます。

| 選択肢 | 向いている用途 |
| --- | --- |
| 構造ワイヤー | 画面構成、導線、情報の優先順位を早く検討したい |
| 詳細ワイヤー | 実在コピー、状態、情報量までレビューしたい |
| UIモックアップ | デザインシステムを反映した完成見本を作りたい |

たとえば、以下のように依頼できます。

```text
$ai-product-designer
作業フォルダは /Users/me/Projects/travel-agent です。
添付した現行画面を改善して、詳細ワイヤーを3案作ってください。
```

## 出力されるもの

案件の作業フォルダ内に、主に以下が作られます。

- `wireframe/`：編集用のHTML/CSS/JS
- `exports/*.html`：構造・詳細ワイヤー用の自己完結HTML
- `renders/`：画面確認用の画像
- `reports/`：UX監査、設計理由、QA記録
- `exports/*.zip`：編集用ソースを含む一式

## その他

- Google Fontsは使用します。
- 外部JavaScript CDN、解析ツール、実データは使いません。
- このSkillはローカルでPython 3とNode.jsを使って品質チェックを行います。通常のCodexデスクトップ環境での利用を想定しています。
