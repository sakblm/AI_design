# くらしスナップ

写真を撮るほど自分専用の「生きたくらしダッシュボード」が育つ、スマホ向けAIエージェントの企画。壁打ちチャットの**最終時点の方向性**を、今後の企画・プロトタイプ制作に使う作業コンテキストとしてまとめた。

> 位置づけ：ここでは写真から得る個人の暮らし情報を起点にする。「くらしスナップ」はこの案件のフォルダ名・仮称であり、サービス名としての確定はまだしていない。

## 企画の核

**何でも撮る → くらしメモリが育つ → 自分に関係する情報や知恵を先回りして教えてくれる。**

レシート、学校プリント、予定表、チケット、持ち物、服、冷蔵庫、家電の説明書などを、種類を選ばず一つの撮影入口から追加する。AIが内容を判断して「くらしメモリ」に整理する。会話や、本人の同意を得た連携情報も材料になる。写真の蓄積を見せること自体より、記憶と外部情報を結びつけた**気づき・生活の知恵・お得情報・具体的な行動提案**を価値の中心に置く。

写真を撮った対象の専門機能へは深く踏み込まない。料理、勉強、推し活、家計管理をそれぞれ完結させるエージェントではなく、そこから読み取れる予定・興味・生活状況を「暮らしに役立つ情報」へつなぐ。中高生から大人まで想定し、短時間で要点が分かる体験を重視する。

## 合意したUXの方向性

| 項目 | 方向性 |
| --- | --- |
| 入口 | 撮影入口は一つ。ユーザーに写真の種類を選ばせない。下部のカメラからいつでも追加できる。 |
| 初回体験 | **3ステップのモーダル型オンボーディング**。「何でも撮るだけ」→「くらしメモリが育つ」→「自分に合う情報・知恵を先回りして提案」。初回の1枚で価値が伝わることも重要。 |
| ホーム | 固定の予定表やカテゴリ一覧ではなく、メモリに応じてカード構成が変わる**ダッシュボード主体**。適度に写真を使うが、読み物マガジンに寄せすぎない。 |
| 優先表示 | 「今、あなたに役立ちそうなこと」を重要度順に見せ、約5秒で要点がつかめる構成。記録カードより、気づき・先回り提案・関連する生活ハックを主役にする。 |
| 提案の根拠 | 写真・会話から得た記憶と、地域、制度、店舗、交通、イベント、Web・SNS等の情報を組み合わせる。詳細画面で「なぜこの提案か」、関連情報、次の行動を示す。 |
| 外部情報の扱い | 天気・交通・地域などは、それ自体のカードを多用せず、関係する提案を作る材料として使う。写真の内容とつながりのない天気情報を並べない。 |
| 会話 | **全画面下部にチャット入力とカメラを常設**し、提案への質問、自由相談、写真追加をいつでもできるようにする。 |
| 記憶の制御 | 「くらしメモリ」で蓄積内容を確認・編集・削除できる。不要な記憶を消したらホームにも反映する想定。 |
| 画面サイズ | スマホ縦長の同一デバイス幅を前提にワイヤーを作る。 |

ホームは「エージェントが今気づいていること」、カード詳細は「判断の理由と具体的な行動」、その先は「会話で深掘り」という流れ。カードの詳細内容はテーマに応じて変える。

## 情報の流れと提案例

1. 写真・会話・本人が許可した連携情報から、事実・一時情報・傾向を「くらしメモリ」に整理する。
2. 地域・制度・店舗・交通・イベント・公開情報など、関連する外部情報と照合する。
3. 今その人に役立つ提案を優先順位付きで表示する。
4. ユーザーは理由を確認し、会話やメモリ編集で結果を変えられる。

| 入力の例 | 提案の方向性 |
| --- | --- |
| レシートと購入傾向 | よく買う商品が近隣店舗で安い、次回の買い物で役立つ情報。 |
| 家電の説明書と購入時期 | 季節やメーカー情報を踏まえた手入れ時期の提案。 |
| ライブチケット | 当日の会場周辺のイベント・交通・必要なら天気を踏まえた準備。推し活管理には踏み込まない。 |
| 学校プリント | 行事・提出期限と地域情報をつないだ準備のヒント。 |
| 服・持ち物 | 季節や使用予定に合う手入れ・使い方の知恵。 |
| 冷蔵庫や食材 | 保存や食生活について、把握できた範囲での気づき。栄養状態を断定しない。 |
| 子どもがいるというメモリ | 関連する新制度の情報など、写真に直接写っていないが暮らしに関係する話題。制度の実施状況・対象条件は別途確認する。 |

具体的な割引、混雑、制度、健康に関する表示は、実データや信頼できる出典で確認してから製品の事実として扱う。SNS由来の暮らしの工夫は有用性を検討し、制度・健康・食品安全などの情報は公式情報等で裏取りする。

## 主要画面

1. 3ステップのオンボーディングモーダル
2. ホーム：可変ダッシュボードと先回り提案
3. 提案カード詳細：理由、関連情報、具体的な行動
4. くらしメモリ：蓄積情報の確認・編集・削除
5. チャット：提案への質問と自由相談

## 次に詰めること

- 何をどの精度で写真から読み取り、ユーザーに確認するか。誤読や推測の訂正方法。
- メモリの保存期間、事実・一時情報・傾向の区別、同意を得る連携範囲、家族情報の扱い。
- 外部情報の取得元、更新頻度、提案の優先順位、根拠と出典の表示方法。
- 「先回り」が役立つ範囲と、通知する条件。初回の写真1枚でも価値が見える体験。
- サービス名とコピーの確定。「くらしスナップ」はチャット内の名称候補の一つで、この案件では仮称として使用。
