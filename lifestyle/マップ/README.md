# くらしマップ

くらしに関するエージェントを作る企画。参照した壁打ちチャットの**最終時点の方向性**を、今後の企画・プロトタイプ制作の作業コンテキストとして記録する。

## 企画の核

**自分では気づけない、暮らしに必要なことが見つかる。** 居住地域、家族構成、時期などに応じて、制度・手続き・地域情報を自分ごととして提示する。検索や質問を待つだけでなく、Agent iを開くたびに「今の自分に必要なホーム」に変わっている体験を目指す。

主な対象は、期限のあること、制度変更、地域固有の情報、季節、ライフステージ。初期の守備範囲は、ごみ・地域、行政手続き、税やお金に関する制度、子育て制度、住まい、防災。旅行・飲食・買い物など他領域の入口を混ぜない。

## 現時点の画面構成

| 画面・機能 | 役割 |
| --- | --- |
| くらしホーム | 入口。時期や状況に応じたカードと「あなたへのおすすめ」を表示。制度や支援の発見はここで扱う。添付のホーム案を基準にし、作り直さない。 |
| くらしマップ | **地域の地図**を中心に、今この生活圏で役立つ情報を示す。ごみ、医療、子育て、手続き、防災などのレイヤーを切り替える。 |
| 対象可能性の提示 | くらしの設定に入力された情報をもとに、ホームの制度・支援カードへ「対象かも」のような短い表示を付ける。カード上に「私に関係ある？」という問いは直接書かない。 |
| 判定結果 | カードから進み、対象になる可能性、判断に使った設定、条件、金額目安、期限、出典を示す。設定を変更でき、「やることを確認する」へつなぐ。確定判定とは表現しない。 |
| やること | 必要な準備・手続き・期限を整理。必要ならAgent iの「タスク」に継続チェックを登録する。 |
| くらし予報 | 今後3か月〜1年ほどの、自分に関係する予定・制度・期限を時系列で表示。新情報や判定結果に応じて更新する。 |

### くらしマップの具体像

- 地図上に「今、この場所で役立つ情報」を優先して表示する。単なる施設検索にしない。
- 例：明日のごみ収集、粗大ごみの持込先、休日診療・夜間小児救急、土曜開庁の窓口、子育て支援施設、避難所・給水拠点、図書館、電池・小型家電の回収場所。
- 上部に「この辺のくらし｜今日知っておくと便利なこと 4件」のような要約を置く。
- Agentへの「乾電池どこで捨てられる？」などの質問に、文章だけでなく**場所を地図で返す**体験を想定する。

### 主要な導線

1. **地域情報**：ホーム → くらしマップ → 地図上の情報 → 詳細／Agentに相談。
2. **制度・支援**：ホームの「対象かも」などが付いたカード → 判定結果（くらしの設定を根拠として表示） → やること確認 → 必要に応じてタスク登録／くらし予報へ反映。追加情報が足りない場合の確認方法は未設計。

## UI・体験上の決定事項

- **下部ナビゲーションを追加しない。** Agent iにないナビゲーションを新設しない。
- 遷移先の検討は、スマホ向け・カード中心・モノトーンのワイヤーフレーム。ホームのUIトーン、コンポーネント、余白感を踏襲する。地図も簡潔なワイヤー表現にする。
- 挨拶の大きな枠は不要という方向。開いた瞬間に役立つ情報を見せる。カードを詰め込みすぎず、行政サービスらしい堅さを抑える。
- Agent iの「タスク」は**予定表ではなく、登録したテーマをAgentが継続して確認する機能**。くらし予報の時系列表示とも役割を分ける。
- 「私に関係ある？」は初期の壁打ち案にあった文言で、現行ラフの画面表示には採用していない。現行ラフではカード上の「対象かも」と、くらしの設定を使った判定結果で自分との関係を伝える。
- 日常の発見はホーム更新を基本とし、プッシュ通知は緊急性・期限・本人の希望などに応じて検討する。

## 企画の狙いと検証事項

差別化の仮説は「日本・地域の暮らしへの深さ」×「AIが自分から動く度合い」。ホームで発見し、設定情報に基づいて対象可能性を示し、将来の予定や継続チェックへつなぐ一連の体験を重視する。以前の議論では「くらしレーダー」を制度発見一覧として使っていたが、地図機能へ変更し、**現行名称は「くらしマップ」**。制度発見はホームの「あなたへのおすすめ」に置いた。

初期ユースケース候補は、ごみ収集・分別、ふるさと納税、確定申告、制度変更、給付・助成、子育て制度、引っ越し、防災、行政手続き、期限のある申請。カードを出す条件、優先順位、必要データ、情報源、通知基準、対象判定の正確さは未設計。ホーム画像にある文言や数字はワイヤー上の例示として扱う。

壁打ち中の「検索・AIでのくらし質問Top50」は公開された実測順位ではなく、複数の資料から推定したテーマ一覧。競合の機能・制度・税の具体的な時期や条件も、このファイルでは**未検証の企画材料**として扱い、外部発表や実装前に一次情報で確認する。
